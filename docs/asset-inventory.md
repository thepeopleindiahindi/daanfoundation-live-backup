## 6. Theme Approach — Recommendation

### Options Considered

| Approach | Pros | Cons |
|---|---|---|
| **Astra + Elementor + Custom CSS** | Fast to build; WP already has both installed; non-destructive to existing setup; client can edit pages visually | Less pixel-perfect than hand-coded; Elementor can be slow; complex animations limited |
| **Hand-coded custom theme** | Full control; lightweight; pixel-perfect parity | Slower to build; harder for client to edit; no visual builder |
| **Full Site Editing (FSE) block theme** | Modern; no builder dependency | Not compatible with existing Astra data; steep learning curve; limited animation support |

### Recommendation: Hybrid — Astra + Elementor + Custom CSS Snippets

**Rationale:**
1. The live site **already has Astra, Elementor, and WooCommerce** installed and configured
2. The React design is visually rich but structurally uses standard patterns (grids, cards, overlays) that Elementor handles well
3. Complex animations (hero crossfade, hover zooms) can be added via **Code Snippets** plugin (already installed) with custom JS/CSS
4. This preserves existing Elementor content, WooCommerce products, and Rank Math SEO settings
5. Fastest path to visual parity

**Implementation plan:**
1. Use Elementor's Theme Builder for header/footer templates
2. Build page templates in Elementor matching the React design
3. Inject design token CSS (`docs/design-tokens.md`) via Code Snippets or child theme
4. Custom JS for hero slideshow and scroll effects via Code Snippets
5. Switch `.htaccess` to point to `index.php` (WordPress) when ready
